# Amine Para — أمين بارا

تطبيق أندرويد لإدارة محل بارافارماسي. يعمل بالكامل على الهاتف وبدون إنترنت.

## ما يعمل الآن
- **المنتجات:** صور، أصناف، سعر الشراء والبيع وهامش الربح، مخزون وحد تنبيه، تاريخ انتهاء، بحث.
- **المبيعات:** سلة، تعديل السعر، دفع كامل أو جزئي، والباقي يُسجَّل ديناً على الزبون، إلغاء فاتورة يعيد المخزون.
- **المشتريات:** تزيد المخزون وتحدّث سعر الشراء.
- **المصاريف والأرباح:** الربح الصافي = ربح المبيعات (بتكلفة وقت البيع) − المصاريف، لليوم/7 أيام/الشهر/السنة.
- **دفتر الزبائن والديون:** ديون ودفعات وسجل لكل زبون، اتصال وواتساب، **تبديل الدرهم/الريال** (1 درهم = 20 ريال) في هذا الدفتر فقط.
- **استوديو التسويق:** 14 قالباً في 7 فئات، 3 مقاسات (مربع/عمودي/ستوري)، 6 لوحات ألوان، خطان، صورة من الهاتف أو منتجاتك أو Pexels، شعار واسم المحل، تصدير PNG بدقة 1080، مشاركة عبر قائمة أندرويد (واتساب/إنستغرام).
- **تذكيرات اختيارية:** صباح/مساء/جمعة/مناسبات (إشعارات محلية، لا نشر تلقائي).
- **عربي وفرنسي** مع RTL/LTR، **نسخ احتياطي** إلى ملف JSON واسترجاعه.

## المال
كل المبالغ أعداد صحيحة بالسنتيم، فلا أخطاء تقريب. الريال = 5 سنتيم بالضبط. إدخال مبلغ بالريال لا يقابل سنتيمات صحيحة يُرفض بدل أن يُقرَّب.

## ما لم يُبنَ بعد
- **المزامنة مع خادم (Supabase) والنسخ الاحتياطي السحابي.** التطبيق يسجّل كل تعديل في طابور محلي (outbox) تمهيداً لها، لكن لا خادم متصل. النسخ الاحتياطي الحالي يدوي إلى ملف.
